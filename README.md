# Gunfight (Zombie Breach)

一个基于 `pygame` 的 2D 俯视角射击游戏。  
你可以在多层地图中战斗、开关门、乘电梯、拾取武器与资源，并对抗普通敌人、精英敌人、Boss 和僵尸。

## 项目亮点

- 多层地图与关卡推进（含电梯楼层切换）
- 枪械系统：射速、弹夹、换弹、不同武器属性
- 战斗系统：普通敌人 / 精英敌人 / Boss
- 新增内容：保险箱、钥匙门锁、僵尸（僵尸会与敌人互殴）
- 战术系统：战争迷雾、雷达、翻滚、手雷、连杀提示
- 交互系统：门、容器、医疗包、弹药箱、武器掉落

## 目录结构

```text
src/
  main.py              # 游戏入口与核心逻辑
assets/images/         # 图片资源
tests/                 # 测试目录（预留）
```

## 环境要求

- Python 3.11+
- pygame

安装依赖：

```bash
python3 -m pip install pygame
```

## 运行方式

```bash
python3 src/main.py
```

语法检查：

```bash
python3 -m py_compile src/main.py
```

## 主要按键

- `W/A/S/D`：移动
- `SPACE`：冲刺
- `左键`：射击（按住连发）
- `R`：换弹
- `L`：无限弹药开关
- `E`：交互（开门、拾取、开锁、开保险箱、乘电梯）
- `1/2`：切换武器
- `Q`：翻滚
- `G`：投掷手雷
- `TAB`：地图开关
- `N`：雷达开关
- `B`：商城开关
- `7`：敌人血量显示开关
- `ESC` / `P`：暂停

## 当前玩法说明

- 地图内会生成门锁与钥匙：先拿钥匙，再开门锁/保险箱。
- 保险箱可提供金币与弹药奖励。
- 僵尸会主动追击并攻击敌人（也会攻击玩家）。
- 敌人子弹可误伤僵尸，战场会出现“敌对单位互殴”。
